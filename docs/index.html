Privacy. Translation is done by Google: the text you type is sent to Google’s translate endpoint. Speech is Google’s too when the engine is set to Google — the text being spoken is sent to Google’s text-to-speech endpoint. The browser-local engine is the single exception: that text never leaves the page.

Your settings, the translation cache (last 300 translations) and your last 20 history entries are kept in this browser’s localStorage, for this site’s origin, on this device. The cache can be erased with the “Clear cache” button. The history has no button of its own: it is removed when you clear this site’s data in your browser. Nothing here can promise that localStorage entries survive — clearing site data, a private window or a browser reset all delete them. Nothing is sent to any server you control, because there is no server.

No offline engine, no download, no build step, no third-party JavaScript.
